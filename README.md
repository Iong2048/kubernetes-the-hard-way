## 🔧 Troubleshooting Common Issues

### Issue: Commands Don't Work
- Double-check you typed them exactly as shown
- Make sure you're in the correct folder
- Check that you have admin privileges

### Issue: Can't Connect to Virtual Machines
- Verify your network settings match the guide
- Restart the virtual machines
- Check your firewall settings

### Issue: Certificates Don't Verify
- Ensure the certificate names exactly match the hostnames
- Check the dates on your certificates
- Redo the certificate steps carefully
